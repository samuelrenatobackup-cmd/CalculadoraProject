🧮 Calculadora Web

Projeto de uma calculadora desenvolvida utilizando HTML, CSS e JavaScript, com foco na prática de lógica de programação e manipulação do DOM.

🚀 Funcionalidades
Adição
Subtração
Multiplicação
Divisão
Porcentagem
Parênteses
Números decimais
Limpar visor
Apagar último caractere
Exibição do resultado
🛠️ Tecnologias
HTML5
CSS3
JavaScript
📌 Objetivo

Praticar conceitos de JavaScript, como funções, variáveis, eventos, manipulação do DOM e estruturas condicionais.

▶️ Como executar

Basta abrir o arquivo index.html em um navegador.

Desenvolvido para fins de estudo e aprendizado.
